# 🦕 Dinosaur Park Incremental Game

**Dinosaur Park** is a captivating incremental game where you manage and grow a dinosaur-themed park. This project showcases expertise in **TypeScript**, **game design**, and **data-driven programming**. Designed with incremental mechanics and a focus on user experience, Dinosaur Park brings players into a world where they strategically expand a dinosaur park, manage resources, and engage in continuous progression.

## 🎮 Game Overview

In **Dinosaur Park**:
- **Manage Resources**: Collect DNA strands and use them to unlock new park features and habitats.
- **Dynamic Gameplay**: Employ strategic upgrades to enhance DNA collection rates.
- **Engaging Mechanics**: Designed with modern programming principles, offering a smooth and engaging gameplay experience.

## 🛠 Tools and Technologies

The project was built with modern tools and technologies:
- **Languages**: TypeScript, HTML5, CSS
- **Tools**: Visual Studio Code, Node.js, Git, GitHub, GitHub Actions
- **Frameworks**: Vite
- **Version Control**: Git and GitHub for collaboration and version tracking
- **Deployment**: Web-based, allowing players to access the game directly via modern browsers

## 🌟 Key Features

### Incremental Game Design
The game follows a classic incremental model:
- Players begin with basic resources and gradually acquire upgrades to increase production rates.
- Strategic decision-making is encouraged as players balance spending resources on immediate gains vs. future growth.

### UI/UX Excellence
The user experience is a priority:
- **Responsive Design**: The game is designed to be accessible on various devices and screen sizes.
- **User-Friendly Interface**: Simple and intuitive interface ensures seamless gameplay and player satisfaction.

### Robust Game Architecture
- **Modular Code**: Game logic and UI components are well-separated, promoting clean, maintainable code.
- **Data-Driven Logic**: Game data, such as upgrade costs and growth rates, is stored in JSON-like structures, allowing for easy expansion and modification.

### Advanced Game Mechanics
- **Real-Time Statistics**: Players see live updates on counters and growth rates, enhancing engagement.
- **Strategic Upgrades**: Each upgrade impacts gameplay and encourages different strategies, keeping the experience fresh and engaging.

## 📋 Project Requirements and Implementation

This project followed an incremental development process with 10 major steps, each tracked via Git commits:

1. **A Clickable Button**: Initial step involved creating a button that players could click to interact with the game.
2. **Counter**: Clicking the button increases a counter representing DNA strands.
3. **Automatic Clicking**: The counter increments automatically, simulating DNA collection over time.
4. **Continuous Growth**: Refined the counter to grow steadily per animation frame for a more fluid experience.
5. **Purchasable Upgrades**: Players could now purchase upgrades to increase DNA collection rates.
6. **Multiple Upgrades**: Additional upgrades with unique effects and prices were introduced.
7. **Price Scaling**: Upgrade prices increase exponentially, making later upgrades more costly and strategic.
8. **Thematic Consistency**: Unified theme for the button, counter, and upgrades to align with the dinosaur park narrative.
9. **Data-Driven Design**: Refactored code to support data-driven updates, enabling easy addition of new upgrades.
10. **Content Expansion**: Added two more upgrades with unique effects and descriptions for added depth.

## 🛠 Deployment and Accessibility

The game was deployed via **GitHub Pages** and **GitHub Actions**. Following each commit, automated workflows ensured successful deployment, allowing players to access the latest version of the game at any time.

## 📈 Development Process and Version Control

Version control was strictly followed, with each development milestone marked as a unique commit:
- **Commit Strategy**: Each major change was committed to allow for easy tracking of progress and to adhere to the principles of incremental development.
- **GitHub Actions**: Automated testing and deployment ensured that the latest version was available without manual intervention.
